# ARAAK Holding Platform — Prototype

Full-stack Next.js prototype for **مجموعة مجموعة اراك**.

## Features
- Arabic RTL responsive corporate experience
- Cinematic ARAAK hero artwork
- Group ecosystem / companies
- Flagship projects / case-study model
- Global footprint
- ARAAK Insights
- Journey and governance
- Investment & partnerships contact form
- Server API endpoint: `POST /api/contact`

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production
```bash
npm run build
npm start
```

## GitHub / Vercel
Import this repository into Vercel. No environment variables are required for the prototype.
